# justdothings

Personal site at https://justdothings.xyz. Vite, React, Tailwind.

```sh
npm install
npm run dev      # http://localhost:8080
npm run build
```

Book data lives in `src/content/books/books.json`. The annotation tool at
`/reading/review` exists only on the dev server.

Response headers (CSP and friends) are set in `public/_headers`.
